# 语料索引（轻量版第一段，15 篇）

本目录是电商售后验证场景的合成语料，平台名称为「星河优选」。文档从完整版 70 篇中选取或保留原文，口径不变。其余语料仍可在 tag `v1-full-postgres` 中查看；后续阶段再补齐约 40 篇（含干扰和 N07）。

## 冲突排序口径（锁定）

当多份文件就同一问题作出不同规定时，按以下顺序确定适用规则：

1. 先比较范围：`sku` → `品类` → `通用`（更具体者优先）。
2. 范围相同，再比较来源：`政策` → `手册` → `FAQ`（政策优先）。
3. 范围与来源均相同，再比较生效日：生效日较晚者优先。

该口径写在 `P01` 第 3 节。干扰文档不得进入上述来源比较（第一段尚未纳入干扰篇）。
