# 语料索引与锁定口径（第一段 25 篇）

本目录是电商售后验证场景的合成语料，平台名称为「星河优选」。文档正文与本索引均写入下列锁定口径，供后续评测使用。

## 冲突排序口径（锁定）

当多份文件就同一问题作出不同规定时，按以下顺序确定适用规则：

1. 先比较范围：`sku` → `品类` → `通用`（更具体者优先）。
2. 范围相同，再比较来源：`政策` → `手册` → `FAQ`（政策优先）。
3. 范围与来源均相同，再比较生效日：生效日较晚者优先。

该口径写在 `P01` 第 3 节，并在相关专项文档中复述。

## 标注约定

后续评测标注使用 `doc_id + section_path + 字符起止`（相对文档正文），不直接标注 `chunk_id`。切分须按稳定标题结构映射到 `section_path`。

`section_path` 规则：由二级标题编号与标题文本组成，例如 `1.适用范围`、`2.时限计算`。
