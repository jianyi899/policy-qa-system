# 90 秒演示台本（五段，轻量版）

本演示使用本机 Streamlit 真实界面与真实模型回答，不是幻灯片，也不是完整版旧视频。页面只监听 `127.0.0.1`，不要把这台开发机暴露到公网。密钥只放本地 `.env`，不要出现在画面或仓库里。

## 启动

安装和数据在评测时使用 `/tmp/policy-qa-stage6-test`（你自己的 Windows 电脑默认仍是 `D:/policy-qa`）。

```bash
export POLICY_QA_HOME=/tmp/policy-qa-stage6-test
python -m app.start
```

浏览器打开：`http://127.0.0.1:8501/`（手动用左侧切换器选择「主路径用户」）或 `http://127.0.0.1:8501/?demo=1`（自动连播五段）。

也可一键录屏（需要本机显示器、Chrome 与 ffmpeg）：

```bash
bash scripts/record_stage6_demo.sh
```

成品视频：`docs/demo/policy-qa-demo-90s.mp4`。

## 五段内容与操作

演示会话注入「主路径用户」（`u-stage4-member`），其下有冰箱订单 `SO-FRIDGE-20D`（签收约 20 天）。工具签名不含 `user_id`。不要在对话里输入身份。

1. **问题（约 10 秒）**  
   停留在首页说明：这是电商售后政策问答系统（轻量版）；先检索条款，再按 SKU → 品类 → 通用套政策；涉及具体订单时先查订单再作答；回答带来源句子。

2. **检索与引用**  
   提问：`手机数码商品还没有激活，签收才 5 天，包装和机身都完好，可以申请七天无理由退货吗？`  
   等待真实回答出现后，停留看清句级引用（`[S#]`、文档编号、章节路径）。

3. **查订单后按范围套政策（必须包含）**  
   提问：`这单冰箱买了 20 天质量问题还能退吗`  
   系统须先查到 `SO-FRIDGE-20D`，再按该单的 SKU、品类和签收时间套政策，不能只凭口述。停留看清订单事实条与结论（质量问题仍可主张，七天无理由窗口已过）。

4. **拒答或转人工**  
   提问：`明天北京会不会下雨？要不要改到货时间？`  
   应拒答或转人工，不得编造天气或条款。新开会话，避免被当成上一单冰箱的追问。

5. **评测结果**  
   展示 README 对比表中的真实测得数字（来自 `reports/test_run3.json` 等已写入报告），包括检索、答题质量、拒答与句级引用。不得编造数字。

全程不要改问题措辞去凑答案。若某次生成失败，按界面真实结果录，不要改用幻灯片或伪造回复。
