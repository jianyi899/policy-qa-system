# 90 秒演示台本（五段）

本演示使用本机 Streamlit 真实界面与真实模型回答，不是幻灯片。页面只监听 `127.0.0.1`，不要把这台开发机暴露到公网。若部署到自有云主机，密钥只放服务端环境变量，不要写入仓库。

## 启动

```bash
bash scripts/start_local_services.sh
# 需要环境中的 DASHSCOPE_API_KEY；Langfuse 为可选，区域使用
# LANGFUSE_BASE_URL=https://jp.cloud.langfuse.com
source .venv/bin/activate
streamlit run app/streamlit_app.py --server.address 127.0.0.1 --server.port 8501
```

浏览器打开：`http://127.0.0.1:8501/`（手动点左侧按钮）或 `http://127.0.0.1:8501/?demo=1`（自动连播五段）。

也可一键录屏（需要本机显示器、Chrome 与 ffmpeg）：

```bash
bash scripts/record_stage7_demo.sh
```

成品视频：`docs/demo/policy-qa-demo-90s.mp4`（本机实录约 84 秒，五段均为 Streamlit 真实界面与真实回答，不是幻灯片）。

## 五段内容与操作

演示会话默认注入用户「主路径用户」（`u-stage4-member`），其下有冰箱订单 `SO-FRIDGE-20D`（签收约 20 天）。工具签名不含 `user_id`。

1. **问题与系统定位（约 10 秒）**  
   停留在首页。说明：这是电商售后政策问答系统；先检索条款，再按 SKU → 品类 → 通用套政策；涉及具体订单时先查订单再作答；回答带来源句子。

2. **检索 + 句级引用**  
   提问：`手机数码商品还没有激活，签收才 5 天，包装和机身都完好，可以申请七天无理由退货吗？`  
   等待真实回答出现后，停留看清句级引用（`[S#]`、文档编号、章节路径）。

3. **冲突消解（Q042：SKU 24 个月覆盖通用 12 个月）**  
   提问：`我买的星河手表 S3（SKU-HX-WATCH-S3，智能穿戴）质量保证期限是多久？不是还有通用 12 个月的规定吗，到底适用哪一个？`  
   停留看清：应答 24 个月，并说明 SKU 专项覆盖通用 12 个月。

4. **查订单后按范围套政策（必须包含）**  
   提问：`这单冰箱买了 20 天质量问题还能退吗`  
   系统须先查到 `SO-FRIDGE-20D`，再按该单的 SKU、品类和签收时间套政策，不能只凭口述。停留看清订单事实条与结论（质量问题仍可主张，七天无理由窗口已过）。

5. **拒答或缓存命中**  
   先问：`明天北京会不会下雨？要不要改到货时间？`（应拒答，不得编造天气或条款）。  
   再把第 2 段的问题原句重问一次，应显示「缓存命中」，首 token 明显更快。

全程不要改问题措辞去凑答案。若某次生成失败，按界面真实结果录，不要改用幻灯片或伪造回复。
